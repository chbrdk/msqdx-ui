## Theme accents (semantic)

Default UI `--accent` = **orange** `#ff6a3b` (`msqdxLight` / `msqdxDark`).  
`--ok` = green, `--warn` = yellow.

Do not invent product accents in chat — cite this file or `@msqdx/ui-tokens`.
