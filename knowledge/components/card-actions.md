# CardActions

Equal-width magazine card action row in `msqdx-ui`.

## Consumers

- Plexon v3: collection / product catalog tiles (`plexon-collection-card-actions` class hook)
- Checkion v3: projects hub tiles (`checkion-collection-card-actions` class hook)

## Notes

- Default `hairline` preserves the magazine top rule.
- Nested Link/span wrappers are supported — children stretch; `.ds-btn` fills width.
