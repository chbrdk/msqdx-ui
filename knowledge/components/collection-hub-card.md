# CollectionHubCard

Magazine Collection / capability-project hub card in `msqdx-ui`.

**Spec:** `specs/domain/msqdx-ui-collection-hub-card.md`  
**Origin:** Brandion `project-panels` collection tiles; CHECKION / PLEXON CSS clones.

## Consumers

- Brandion / CHECKION `/projects` (+ Brandion guidelines tiles)
- PLEXON Collection magazine cards (`CollectionProjectCard`)
- AUDION / CREATION / METRON / VIDEON projects hubs
- Non-project catalogs stay on `HubIndexCard` (compositions, cuts, KPIs, datasets stubs)
