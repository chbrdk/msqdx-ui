# TokenPicker

Layer: `molecules` (Storybook group: Organisms / editor chrome)

Dense token-path picker for inspect bindings. **Values are token paths only** — swatches are display-only; there is no free CSS / hex entry.

**Spec:** `specs/domain/msqdx-ui-token-picker.md`

## Stories

- Default (compact popover)
- WithClear (`onClear`)
- AllowNone
- DenseList (`variant="list"`)
- WithCycle (`allowCycle` −/+)
- FontFamily (`fontPreview` on the value label)
- **Browser** — floating multi-context window (search, scopes, Recent, drag, keyboard)
- **BrowserColorGrid** — color swatch grid when `previewKind="color"`

## Usage

```tsx
import { TokenPicker } from '@msqdx/ui'

<TokenPicker
  label="Radius"
  browser
  allowCycle
  previewKind="radius"
  contextTitle="Binding for: Desktop"
  options={[{ path: 'radius.md', label: 'radius.md · 8px', preview: '8px', category: 'radius' }]}
  value={binding}
  onChange={(path) => setToken(path)}
  onClear={() => clearToken()}
  scopes={[
    { id: 'suggested', label: 'Suggested' },
    { id: 'radius', label: 'Radius' },
    { id: 'all', label: 'All' },
  ]}
  suggestedPaths={['radius.md']}
  allowNone
  emptyLabel="—"
  noneLabel="None"
/>
```
