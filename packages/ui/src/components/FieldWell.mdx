# FieldWell

Layer: `molecules`

Power-BI-style **field binding** chrome for dashboard compose inspectors. Pair with [`ExpressionField`](/docs/molecules-expressionfield--docs) inside `FieldWellStack`.

Spec: `specs/domain/msqdx-ui-field-well.md`

## Usage

- Pass **`role`** (Value / Category / …) on the well; omit `label` on nested `ExpressionField`.
- Set **`bound`** from whether the app considers the slot filled.
- Toggle **`dropActive`** while a drag hovers the inspector slot.
