# LayersPanel

Layer: `organisms`

Scene structure tree for composition editors. Apps map domain nodes to `{ id, label, type?, children? }`.

Optional sibling reorder via `onMoveUp` / `onMoveDown` or `onReorder` (no drag-drop in the DS).

**Spec:** `specs/domain/msqdx-ui-layers-panel.md`  
**Related:** `ComponentPalette` (left rail insert) · CREATION `editor-workspace.md`

## Stories

- Default
- Nested selection
- Empty
- With sibling reorder

## Usage

```tsx
import { LayersPanel } from '@msqdx/ui'

<LayersPanel
  title="Layers"
  items={[
    {
      id: 'root',
      label: 'Page',
      type: 'Stack',
      children: [{ id: 't1', label: 'Title', type: 'Text' }],
    },
  ]}
  selectedId={selectedId}
  onSelect={setSelectedId}
  onReorder={(id, direction) => /* mutate sibling order in app state */}
/>
```

Hide/lock/drag-drop stay in the app — select, expand, and optional ▲▼ sibling move are chrome only.
