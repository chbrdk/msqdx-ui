## Do and Don't

### Do

- Pass `name` for initials and accessible label when no `src`.
- Use `alt` when the image conveys identity.

### Don't

- Do not use decorative avatars without `aria-hidden` / empty alt when purely ornamental.

## Accessibility

Initials mode uses `role="img"` + `aria-label`. Image mode relies on `alt`.
