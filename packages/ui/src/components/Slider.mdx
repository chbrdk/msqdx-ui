# Slider

Layer: `atoms`

Tokenized interactive range — see `specs/domain/msqdx-ui-slider.md`.

## Usage

```tsx
import { Slider } from '@msqdx/ui'

<Slider value={pct} onChange={setPct} onCommit={save} aria-label="Score" />
```

Prefer wrapping with `Meter` / `MeterList` when a label + value readout is needed.
