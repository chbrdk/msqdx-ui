# MSQDX UI

Central React + CSS-variable design system extracted from ECHON V3.

Packages:
- `@msqdx/ui-tokens` — token exports
- `@msqdx/ui` — shared primitives, CSS layers, Storybook catalog

Commands:
- `pnpm install`
- `pnpm build`
- `pnpm test`
- `pnpm storybook`
- `pnpm ds:add ButtonLike --layer atoms`
